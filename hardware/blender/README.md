# Final Thesis Enclosure Model

[Download the final Blender model](Rowing_Thesis_final_print.blend)

`Rowing_Thesis_final_print.blend` is the final enclosure design supplied by Miled Mahdoui for the rowing IMU thesis prototype. It replaces the earlier enclosure and clamp variants in this directory.

## Opening and exporting

1. Download the `.blend` file and open it in Blender.
2. Check object dimensions, units, and the parts to export.
3. Export the required parts as STL or another format supported by your slicer.
4. Check print orientation, supports, clearances, and material settings before printing.

This is an editable Blender source file, not a ready-to-run printer file. Print settings and water resistance are not validated by this repository update.

Earlier model versions remain available in the Git history.
